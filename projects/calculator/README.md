# TEXT CALCULATOR #

### DESCRIPTION ###
This project is to create a text calculator, which should take an arbitrary input string validate that it's a mathematical equation and then compute the result. The input of the calculator is a STRING not numeric values. Based on the textual values in the equation the calculator should parse a series of operations, and return a result to the output. Additional functions will be added as desired. This is meant to be a learning experience to re-familiarize with C fundamentals.

### OBJECTIVES ###
This project should be fully implemented from scratch, it should not use external libraries or header files except for basic input/output operations. Any noted exceptions to this rule should be justified with an explanation. As this is a learning experience I will not be using AI generated code. I am not against AI in it's entirety it's just simply not the objective of this project. I am allowed to consult AI on questions in terms of implications and performance but I'll be strictly avoiding codegen. I'm also allowed to use AI for documentation purposes because writing markdown is tedious
### STRUCTURE ###
The main.c is the calculator itself, it's the main runtime of the application. There's also an equation parser and there will likely be some other utilities written as it's built out. The README should be updated with relavent documentation as features are added and/or link to supplemental documentation where needed.
